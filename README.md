# Shop Platform – DevSecOps Project

A microservices-based shopping platform built with the MERN stack and designed using DevSecOps best practices.

## Architecture
- Auth Service (JWT-based authentication)
- Product Service (catalog & categories)
- Cart Service (Redis-backed cart)
- Order Service (immutable order records)
- Frontend (React + Vite)

## DevSecOps Goals
- CI per microservice
- Code quality & security scanning
- Containerized services
- GitOps-based deployment
- Observability with Prometheus, Grafana & Loki

## Tech Stack
- Node.js, Express, MongoDB, Redis
- React (Vite)
- Docker & Docker Compose
- Jenkins, SonarQube, Trivy
- Kubernetes, Helm, ArgoCD
